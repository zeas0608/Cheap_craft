# Cheap Craft

ブラウザで遊べる3Dブロックサンドボックスゲーム。

## [▶ ゲームを起動する](https://zeas0608.github.io/Cheap_craft/)

インストール・ダウンロード不要。PCのブラウザで遊べます。

## 採掘・設置リーチ（開発仕様）

| ゲームモード | 最大リーチ | 実装状況 |
| --- | ---: | --- |
| クリエイティブ | 5 ブロック | 実装済み |
| サバイバル | 4.5 ブロック | 将来実装 |

視点（プレイヤーの目の位置）から照準が当たるブロック面までの距離で判定する。採掘・設置・選択枠に共通のリーチを適用する。サバイバル実装時は `BLOCK_REACH.survival` を使用する。

## 地上移動速度（開発仕様）

| 移動状態 | 最高速度 |
| --- | ---: |
| 通常歩行 | 4.317 ブロック/秒 |
| ダッシュ | 5.612 ブロック/秒 |

ダッシュは通常歩行より約30%速い。Wキーを素早く2回押して開始し、Wキーを離すと解除する。加速・減速、水中移動、スニーク、飛行は別の既存設定を維持する。

## 飛行速度・ワールド生成（開発仕様）

クリエイティブの水平飛行速度は通常 10.8 ブロック/秒、ダッシュ 21.6 ブロック/秒。上昇・下降速度は従来の別設定を維持する。

新規ワールドのシード未指定時とテスト用リセット（Ctrl + Alt + R）は新しいランダムシードを使用する。既存ワールドの再開時は保存済みシードを維持する。ロード画面は最低 1.8 秒表示する。

## サバイバル 第1段階（v1.27）

ワールドごとのゲームモード選択・保存、体力20、空腹20、経験値レベルとバーのHUDを実装。既存ワールドはモード未指定ならクリエイティブとして扱う。サバイバルのリーチは4.5ブロック、飛行不可。採掘時間・ダメージ・空腹消費・経験値獲得・実インベントリは未実装。既存のクリエイティブ用アイテム欄を暫定利用し、64の数量表示はUI確認用。退出時は最低1.8秒のセーブ画面を表示する。

## クラフト拡張（v1.53）

通常の2×2クラフトと設置した作業台の3×3クラフト、定形・不定形レシピ58件に対応。サバイバルで作業台を右クリック／モバイルの使用ボタンで開けます。道具・防具・部分形状の建材などの固有機能は開発中です。レシピの将来実装仕様は [CRAFTING.md](CRAFTING.md) に記録しています。

## テクスチャ拡張（v1.54）

設定 → リソースパック →「統合版の公式素材を読み込む」で、Mojangの公開サンプルから端末に素材を取得します。JAR / ZIP / MCPACK のローカル読み込みも対応。79アトラス枠のPNG・TGA素材と22種の形状アイコンをサポートし、取得した素材はブラウザ内に保存します。標準に戻すボタンで解除できます。公開リポジトリに新たな公式画像ファイルは同梱していません。取得できない素材は従来の表示を維持します。

- 参照: [日本語Minecraft Wiki](https://ja.minecraft.wiki/)、[アイテムテクスチャ一覧](https://minecraft.wiki/w/List_of_item_textures)
- ファイル対応: [Mojang Bedrock Samples](https://github.com/Mojang/bedrock-samples/tree/15701fa9c13923f12662984c32c124327e40e3d3/resource_pack/textures)（固定コミットのファイル一覧で79枠すべて確認済み）
- 日本語Wikiの画像本体はアクセス制限のため直接取得できませんでした。公式素材はMinecraft EULAの対象です。階段・フェンス等のアイコンは素材面から簡易形状を描画しており、本家モデルそのものではありません。

## チェスト公式テクスチャ（v1.59）
Mojang Bedrock Samples の固定コミット `15701fa9c13923f12662984c32c124327e40e3d3` の `resource_pack/textures/entity/chest/normal.png` と `double_normal.png` を起動時に取得し、モデルの面ごとに元のピクセルを切り出して端末内に保存します。大チェストでは幅30pxの面を15pxずつ使用し、単体画像の中央境界を繰り返さない方式です。標準テクスチャに戻すと自動取得を無効にできます。設定から公式パックを再取得すると有効になります。オフライン・取得失敗時は中央の境界を除いた暫定素材にフォールバックします。公式画像そのものは公開リポジトリには同梱していません。

## v1.68 落下ブロック・GUIの時間経過・ドラッグ分配
- 実装済みの砂（ブロックID 4）は支えが消えるか空中に置かれると、20TPSの落下エンティティになり、空気・水・草花を通過して着地する。積層した砂は下から順に連鎖落下する。WebGLと簡易描画の両方に立体描画し、落下途中もセーブする。旧ワールドの浮いた砂も読み込み時に検出する。
- インベントリ・チェスト・作業台は操作だけを止め、物理・モブ・水・植物・アイテム・経験値・体力と空腹の更新を継続する。明示的な一時停止ではワールド更新を止める。Esc/EはGUIを閉じるイベントとして消費する。
- PCドラッグの均等分配は実際のアイテムと個数をリアルタイム表示する。64個なら2枠で32/32、3枠で21/21/21とカーソルに1個。右ドラッグは1個ずつ。リリース時に確定し、キャンセル時は確定前の状態を保持する。タッチは従来の1個ずつ配置する方式。
- 公式素材は TEXTURE_SOURCES と特殊モデルの対応表に基づき個別取得する。新規アイテムには素材対応を同時に追加し、公式素材の再読み込みが必要。公式画像は同梱しない。
