# Cheap Craft

ブラウザで遊べる3Dブロックサンドボックスゲーム。

## [▶ ゲームを起動する](https://zeas0608.github.io/Cheap_craft/)

インストール・ダウンロード不要。PCのブラウザで遊べます。

## 採掘・設置リーチ（開発仕様）

| ゲームモード | 最大リーチ | 実装状況 |
| --- | ---: | --- |
| クリエイティブ | 5 ブロック | 実装済み |
| サバイバル | 4.5 ブロック | 将来実装 |

視点（プレイヤーの目の位置）から照準が当たるブロック面までの距離で判定する。採掘・設置・選択枠に共通のリーチを適用する。サバイバル実装時は `BLOCK_REACH.survival` を使用する。
